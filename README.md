# 計算カード (mojishiki-card)

計算を **段階別に** 練習する アプリです。6つの 単元が、一次方程式までの「みち」に なっています。
1回 10問。テンキーで 答えを 入れる か、カードを めくって 答えを 見る（フラッシュ）か を えらべます。

公開URL: https://mypeco.github.io/mojishiki-card/

もとは「文字式カード」と「小数カード」の 2つの アプリでした。いまは この アプリの
⑤ 文字式・② 小数の 計算 に 入っています（むかしの `/shosu/` は トップへ 案内します）。
前の アプリの プロフィール・きろく・バッジは、はじめて 開いた ときに 自動で 引きつぎます
（同じ なまえの 人は 1人に まとめます。もとの データは 消しません）。

UI/UXは [mypeco/gakushu-ui-kit](https://github.com/mypeco/gakushu-ui-kit) に準拠。採用ずみのバージョン: 1.21.5

## 単元と レベル

### ① 整数の 計算

| レベル | 内容 | 例 |
|---|---|---|
| 1 | たし算（くり上がり） | 8 + 7 |
| 2 | ひき算（くり下がり） | 13 − 7 |
| 3 | 2けたの たし算・ひき算 | 36 + 47 |
| 4 | かけ算（九九と 2けた × 1けた） | 23 × 4 |
| 5 | わり算（わりきれる） | 84 ÷ 4 |
| 6 | 計算の じゅんじょ | 3 + 4 × 5 |
| 7 | かっこの ある 計算 | (8 − 3) × 4 |
| 8 | 正負の数の たし算・ひき算 | 5 − (−3) |
| 9 | 正負の数の かけ算・わり算 | −6 × 3 |
| 10 | 正負の数の 四則と 累乗 | (−3)² |

### ② 小数の 計算

| レベル | 内容 | 例 |
|---|---|---|
| 1 | 0.1の たし算（答えは 1より 小さい） | 0.3 + 0.4 |
| 2 | 0.1の ひき算 | 0.8 − 0.5 |
| 3 | 1を またぐ 計算 | 0.7 + 0.6 |
| 4 | 整数の ある 小数 | 2.4 + 1.3 |
| 5 | 100分の1の 位 | 0.25 + 0.14 |
| 6 | 小数 × 整数 | 0.6 × 4 |
| 7 | 小数 ÷ 整数 | 2.4 ÷ 3 |
| 8 | 10倍・1/10 | 0.35 × 10 |
| 9 | 小数 × 小数 | 0.3 × 0.4 |
| 10 | 小数 ÷ 小数 | 1.2 ÷ 0.3 |

ヒントは、いま 解いて いる 問題の ひっ算の 図です（答えの 数字は 出しません）。

### ③ 約数と 倍数

| レベル | 内容 | 例 |
|---|---|---|
| 1 | 倍数の ならび | 6, 12, 18, □ |
| 2 | 約数を ぜんぶ | 12 → 1, 2, 3, 4, 6, 12 |
| 3 | 最小公倍数（かんたん） | 3 と 4 |
| 4 | 公約数を ぜんぶ | 12 と 18 |
| 5 | 最大公約数 | 24 と 36 |
| 6 | 最小公倍数 | 6 と 8 |
| 7 | 3つの 数 | 4, 6, 8 |

「ぜんぶ」の 問題は `,` キーで 区切って 入れます。たりない ときは「あと 2こ あるよ」と 出ます。

### ④ 分数の 計算

| レベル | 内容 | 例 |
|---|---|---|
| 1 | 約分 | 6/8 |
| 2 | 分母が 同じ たし算・ひき算 | 2/7 + 3/7 |
| 3 | 分母が ちがう（かんたん） | 1/2 + 1/4 |
| 4 | 分母が ちがう（通分） | 1/4 + 1/6 |
| 5 | 分数 × 整数・÷ 整数 | 2/9 × 3 |
| 6 | 分数 × 分数 | 2/3 × 3/4 |
| 7 | 分数 ÷ 分数 | 3/4 ÷ 3/8 |
| 8 | かけ算・わり算の まじった 計算 | 2/3 × 3/4 ÷ 1/2 |

分数は 分数キー（□ の 上に □）で 分子と 分母を 区切ります。答えは 仮分数か 整数。
約分 しきれて いない ときは「まだ 約分 できるよ」と 出ます。

### ⑤ 文字式

| レベル | 内容 | 例 |
|---|---|---|
| 1 | 文字の 項の たし算 | 3x + 5x |
| 2 | 文字の 項の ひき算 | 7x − 3x |
| 3 | 負の数が でてくる 計算 | 2x − 7x |
| 4 | 数の 項が まざった 計算 | 4x + 3 + 2x |
| 5 | 文字式 × 数・÷ 数 | 3x × 4 |
| 6 | 分配法則 | 3(2x + 4) |
| 7 | かっこの ある たし算・ひき算 | (5x + 3) − (2x + 1) |
| 8 | 累乗の 表し方 | 2 × x × x = 2x² |
| 9 | 中2チャレンジ | 3x × 2x = 6x² |

`x` を 続けて 押すと 累乗に なります（`x` → `x²` → `x³`）。

### ⑥ 一次方程式

| レベル | 内容 | 例 |
|---|---|---|
| 1 | 移項して とく | x + 5 = 12 |
| 2 | 係数で わる | 3x = 12 |
| 3 | 分母を かける | x/3 = 4 |
| 4 | 移項してから わる | 3x + 5 = 20 |
| 5 | 両辺に x が ある | 5x − 3 = 2x + 9 |
| 6 | かっこの ある 方程式 | 2(x + 3) = 14 |
| 7 | 係数が 小数 | 0.3x + 0.5 = 2 |
| 8 | 係数が 分数 | x/2 + 1 = 4 |
| 9 | 答えが 分数 | 3x = 2 → x = 2/3 |

どの 単元にも さいごに **まとめ**（ランダム出題）が あります。まとめには ヒントが ありません
（ヒントなしで できるかを 確かめる 回）。

## 特徴

- **テンキー** — その レベルに 要る キーだけ 出ます（キーの 場所は 単元が かわっても 動きません）。
  パソコンの キーボードでも 入力できます（数字・Enter・Backspace など）
- **フラッシュ** — カードを 押すと 答えが 出ます。「あってた／ちがった」を 自分で つけて つぎへ
- **まちがえても 画面は 進みません。** 理由が あれば 添えます（「＋と −を たしかめよう」「小数点の 位置を たしかめよう」など）
- **ヒント** — 押した ときだけ、同じ レベルの「れい」と 手じゅんを 出します（答えは 出しません）
- **おわりの 画面** — 「10もん中 8もん、1かいめで せいかい」と 時間。前の 回と くらべられます。まちがえた 問題だけ 解き直せます
- **きろく** — 単元・レベルごとの 回数・💮（テンキーで ぜんぶ 1回目で 正解）・いちばん 短い 時間、さいきんの きろく
- **つかう人** — 3人まで。なまえ・アイコン・いろ だけ。端末の 中（localStorage）に 保存し、サーバーには 送りません
- **せってい** — 効果音・うごき を それぞれ オフに できます（うごきは 端末の「視差効果を減らす」にも したがいます）
- 書体は BIZ UDPゴシック（自前で 持って いて、学校の ネットワークなどで 外に つながらなくても 表示が くずれません）

## 開発

```bash
npm install
npm run dev          # http://localhost:5173/
npm run check        # 点検（問題と 答え・見た目の 決めごと・キットの ファイル）
npm run build        # dist/ に ビルド
npm run build:fonts  # 書体を 作りなおす（文字を ふやした とき。となりに ../gakushu-ui-kit が 要る）
```

くわしい 決めごとは [`CLAUDE.md`](CLAUDE.md)（下半分が この アプリ 固有の こと）。

## 技術スタック

- React 18 + Vite
- Tailwind CSS 3.4（Vite で ビルド。CDN は 使わない。色・うごきは gakushu-ui-kit の トークン）
- BIZ UDPGothic（使う 文字の ぶんだけ 自前ホスト）
- localStorage（つかう人・きろく）。Dexie は 前の アプリ（IndexedDB）からの 引きつぎ だけに 使う
- Web Audio API（効果音）

`main` ブランチへの push で GitHub Pages に 自動デプロイされます（`.github/workflows/deploy.yml`）。
PR では `.github/workflows/check.yml` が 点検と ビルドを 走らせます。
