# 文字式カード (mojishiki-card)

中学1年生の「文字式の計算」を、暗算レベルの問題で段階別にトレーニングできるフラッシュカード式計算アプリです。
[kuku-card](https://github.com/mypeco/kuku-card)(九九カード)のアーキテクチャをベースにしています。

このリポジトリには2つのアプリが入っています。

| アプリ | 対象 | パス | 公開URL |
|---|---|---|---|
| 文字式カード | 中1「文字式の計算」 | `/`(`src/`) | https://mypeco.github.io/mojishiki-card/ |
| [小数カード](#小数カード-shosu-card) | 小学生「小数の四則計算」 | `/shosu/`(`src/shosu/`) | https://mypeco.github.io/mojishiki-card/shosu/ |

## 特徴

- **テンキー入力モード** — 数字・`x`・`＋`・`−` キーで答えの式を入力して即判定
  - `3x + 5x` の答えなら `8` `x` `OK` と押すだけ
  - `x` を続けて押すと累乗になる(`x` → `x²` → `x³`)。`2x²` なら `2` `x` `x` `OK`
  - 値は合っていてもまとめきれていない答え(例: `3x+5x`)には「もっと簡単にできるよ」とヒント
- **フラッシュカードモード** — タップで答えをめくる暗算練習
- **段階別レベル(8段階)** — 暗算でこなせる係数の範囲だけで出題
- **記録** — レベル別のチャレンジ回数・100%達成バッジ(💮)・ベストタイム、履歴一覧
- **プロフィール** — 複数ユーザーをローカル(IndexedDB)に保存。サーバー不要
- 効果音(Web Audio)、スマホ・タブレット最適化

## レベル構成

| レベル | 内容 | 例 |
|---|---|---|
| 1 | 文字の項のたし算 | 3x + 5x |
| 2 | 文字の項のひき算 | 7x − 3x |
| 3 | 負の数がでてくる計算 | 2x − 7x |
| 4 | 数の項がまざった計算 | 4x + 3 + 2x |
| 5 | 文字式 × 数・÷ 数 | 3x × 4, 12x ÷ 3 |
| 6 | 分配法則 | 3(2x + 4) |
| 7 | かっこのあるたし算・ひき算 | (5x + 3) − (2x + 1) |
| 9 | 累乗の表し方 | 2 × x × x = 2x² |
| 10 | 中2チャレンジ(単項式の乗除・同類項) | 3x × 2x = 6x² |
| 総合 | ミックス | レベル1〜9からランダム |

## 小数カード (shosu-card)

小学生の「小数の四則計算」を暗算レベルで段階別にトレーニングするアプリです。
文字式カードと同じ作り(テンキー/フラッシュ・レベル別記録・プロフィール)で、
問題と入力キーを小数用にしてあります。記録とプロフィールは文字式カードとは別に保存されます。

- **テンキー入力モード** — 数字と `.` キーで答えを入力
  - 数字はあっているのに値がちがうとき(`0.12` を `1.2` と答えたなど)は「小数点の位置をたしかめよう」とヒント
  - `0.30` や `.5` のような書き方も正解にする
- **フラッシュカードモード** — タップで答えをめくる暗算練習
- 出題はすべてわりきれる問題だけ。答えがマイナスになる問題は出ません

### レベル構成

| レベル | 内容 | 例 |
|---|---|---|
| 1 | 0.1のたし算(答えは1より小さい) | 0.3 + 0.4 |
| 2 | 0.1のひき算 | 0.8 − 0.5 |
| 3 | 1をまたぐ計算(くり上がり・くり下がり) | 0.7 + 0.6, 1 − 0.4 |
| 4 | 整数のある小数のたし算・ひき算 | 2.4 + 1.3, 5 − 1.8 |
| 5 | 100分の1の位 | 0.25 + 0.14, 1 − 0.35 |
| 6 | 小数 × 整数 | 0.6 × 4, 0.25 × 4 |
| 7 | 小数 ÷ 整数 | 2.4 ÷ 3, 0.3 ÷ 6 |
| 8 | 10倍・100倍・1/10・1/100 | 0.35 × 10, 4.2 ÷ 100 |
| 9 | 小数 × 小数 | 0.3 × 0.4, 1.2 × 0.4 |
| 10 | 小数 ÷ 小数 | 1.2 ÷ 0.3, 0.24 ÷ 0.4 |
| 総合 | ミックス | レベル1〜10からランダム |

## 開発

```bash
npm install
npm run dev      # 開発サーバー
                 #   文字式カード http://localhost:5173/mojishiki-card/
                 #   小数カード   http://localhost:5173/mojishiki-card/shosu/
npm run build    # dist/ に2アプリまとめてビルド
```

## 技術スタック

- React 18 + Vite
- Tailwind CSS (CDN)
- Dexie (IndexedDB) — 記録・プロフィールの保存
- Web Audio API — 効果音

`main` ブランチへの push で GitHub Pages に自動デプロイされます(`.github/workflows/deploy.yml`)。
